# NetLogo Multi-LLM Extension - Comprehensive Configuration Reference
# This file contains ALL possible configuration options and values
# Use this as a reference when setting up different providers

# =============================================================================
# IMPORTANT NOTES
# =============================================================================
# 
# Configuration Precedence: Runtime commands > Config file > Built-in defaults
# - Use config file for persistent settings (recommended)
# - Runtime commands (llm:set-provider, etc.) override config file values
# - Built-in defaults apply only if no config file or runtime command is used
#
# Immediate Validation:
# - When loading config or setting provider, validation happens immediately
# - Cloud providers (OpenAI, Anthropic, Gemini) require API keys
# - Ollama requires the server to be running and reachable
# - Invalid configurations throw helpful errors with setup instructions
#
# Provider-Specific Keys:
# - Use provider-specific keys: openai_api_key, anthropic_api_key, gemini_api_key
# - This allows configuring multiple providers at once
# - Generic 'api_key' still supported for backward compatibility
#
# Getting Help:
# - Use 'print llm:provider-help "provider-name"' for setup instructions
# - Use 'print llm:provider-status' to see which providers are ready
# - Use 'print llm:active' to verify current provider and model
